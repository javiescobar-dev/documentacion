#### GitLens:

Utilizada para gestionar el control de versiones de git desde el propio VS Code

#### Github Pull Request:

Utilizada para poder crear PR, revisarlas, añadir comentarios o reviews y gestionar issues desde el propio VS Code

#### Error lens:

Utilizada para resaltar errores, warnings y la información correspondiente de forma más visual y útil

#### Checkstyle:

Utilizada para comprobar el estilo del código y ajustar tus propias reglas de estilo en un fichero xml (clic derecho en el fichero y establecer como configuración general de Checkstyle) en el proyecto.

#### SonarQube (SonarLint):

Utilizada para detectar bad smells, errores y vulnerabilidades y te los muestra mientras escribes el código.
