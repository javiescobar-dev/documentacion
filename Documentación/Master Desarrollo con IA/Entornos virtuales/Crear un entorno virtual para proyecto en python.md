
#### Crear el entorno virtual en la raiz del proyecto:

Esto crea la "caja" donde gestionaremos las instalaciones para este proyecto, sin instalarlas de forma general en toda la máquina

```bash
# puede variar según sistema operativo, dejo el de windows con powershell
# python3 -m venv .venv
python -m venv .venv
```

#### Activar el entorno virtual:

```sh
# puede variar según sistema operativo, dejo el de windows con powershell
# source .venv/bin/activate
.\.venv\Scripts\Activate.ps1
```
